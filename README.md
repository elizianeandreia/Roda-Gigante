# Roda_gigante
🎡 <strong>Roda-Gigante Interativa</strong><hr>
Projeto front-end animado feito com <b>HTML</b>, <b>CSS</b> e <b>TypeScript</b>, que simula uma roda-gigante em movimento. Inclui controles para iniciar, pausar e trocar dinamicamente as cores das cabines. Um exemplo prático de animações com CSS combinadas com interatividade via TypeScript e manipulação do DOM.
